# Supermarket Sales Analysis

## Project Description
Analyzing supermarket sales data to uncover trends, patterns, and actionable business insights using data analysis and visualization techniques.

---

## Dataset
- Dataset: Supermarket Sales Dataset
- Contains: Branch, Product line, Quantity, Unit price, Total sales, Payment method, Customer rating
- Source: [Kaggle Supermarket Sales Dataset](https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales)

---

## Tools Used
- Excel or Google Sheets (for data cleaning, analysis, and visualization)
- Charts: Bar charts, Pie charts, Line charts, Heatmaps

---

## Analysis / Approach
- Cleaned and organized the dataset
- Calculated total sales, average sales, and top-selling products
- Analyzed sales trends by branch, product category, and payment method
- Visualized data using charts for better insights

---

## Key Insights / Findings
- Top-performing product categories and branches
- Most preferred payment methods by customers
- Trends in sales over time or by branch
- Customer rating analysis

---

## How to View / Use
- Download the CSV file from `data/` folder
- Open `Supermarket_Sales_Analysis.xlsx` or Google Sheets file to explore charts and analysis
